# Web button panel

A single page for repetitive actions, without a terminal: images / normal / agents modes, state, health, update, backup,
and review / merge of Hermes agent branches.

## Installation (once)

On AiBeast:

```
lab panel install
```

The command creates a user service (`aibeast-panel`), starts it, and prints an address like
`http://127.0.0.1:3011/login?t=…`.

On your PC: the line `LocalForward 3011 127.0.0.1:3011` is part of the configuration generated by `lab client` (see
`docs/remote-access.md`); reopen the tunnel, then open the printed address **once**. A 30-day cookie keeps you logged in;
after that `http://127.0.0.1:3011` is enough (link also in the portal).

Other commands: `lab panel token` (print the address again), `status`, `logs`, `restart`, `uninstall`.

## What each button does

| Button | Command run |
|---|---|
| Images / normal / agents mode | `lab mode images` / `normal` / `agents` |
| State | `lab mode status` |
| Health | `lab doctor` |
| Update (confirmation) | `lab update` |
| Backup (confirmation) | `lab backup run` |
| Hermes: Review / Full diff | `lab dev review PROJECT BRANCH [--diff]` |
| Hermes: Merge (confirmation) | `lab dev merge PROJECT BRANCH --yes` (tests run again first; failure = nothing merged) |

One action at a time: while one is running, the buttons are greyed out and the server answers 409 to any other request.
The output is shown live.

## Security

- The server only listens on `127.0.0.1`; it is only reachable through the SSH tunnel.
- Token access (`~/.config/aibeast-panel/token`, mode 0600) exchanged for an `HttpOnly` / `SameSite=Strict` cookie.
- Action requests also require an `X-Panel` header, a local `Host` and a local `Origin` (against third-party web pages
  and DNS rebinding).
- Closed list of actions: the browser never sends a command, only a name.
- For Hermes, project and branch are validated by regular expression **and** must appear in the `dev.sh pending` list;
  merging requires an explicit confirmation.
- Outputs are stripped of escape sequences and displayed as plain text.

The token gives the power to start an update or a merge: do not paste it into a conversation or a repository.

## Known limits

- The panel does not start Hermes in a project (interactive session): `lab dev start NAME` or `AiBeast-Hermes.bat`.
- The default model is still chosen with `lab config set MODEL NAME` (no button).
- An action does not survive a restart of the service; an interrupted `lab update` is resumed in a terminal.

## What is not verified

- Tested here with fake `lab` and `dev.sh` (`scripts/test-panel.sh`, 29 checks): authentication, Host/Origin, action
  list, lock, branch validation, escape filtering. The systemd service (`lab panel install`), `loginctl enable-linger`
  and the actual display in a browser have not been confirmed on a real machine.
- The interface has not been seen in a browser; only the JavaScript syntax was checked.
- The output of the real `lab update` (colours, progress bars) may be less readable in the page than in a terminal.
